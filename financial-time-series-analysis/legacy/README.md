# Prototipi storici

Questa cartella conserva la prima implementazione monolitica della pipeline e
dei generatori di report. I file sono mantenuti esclusivamente come riferimento
evolutivo: non fanno parte del pacchetto installabile, della CLI supportata o
della suite di test corrente.

Per eseguire il progetto usare `financial-ts` e i moduli in `pipelines/`,
`reporting/`, `evaluation/` e `strategy/`, come descritto nel README principale.
