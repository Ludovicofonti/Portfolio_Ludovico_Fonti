# Scoring geospaziale di asset fisici

## Contesto

In un contesto professionale era necessario valutare in modo più oggettivo un insieme di asset fisici geolocalizzati, integrando informazioni territoriali, caratteristiche dell'asset e indicatori di esposizione.

## Obiettivo

Costruire un framework analitico per stimare uno score comparabile tra asset, supportando analisi esplorative, prioritizzazione e interpretabilità dei risultati.

## Soluzione

Ho contribuito alla progettazione di una pipeline ML e geospaziale che integra fonti dati eterogenee, feature engineering territoriale, modelli predittivi e strumenti di interpretabilità. L'approccio è stato orientato alla spiegabilità e alla validazione della coerenza dei risultati.

## Ruolo

Sviluppo della pipeline dati, feature engineering geospaziale, modellazione predittiva, validazione e costruzione di output analitici per stakeholder non tecnici.

## Competenze dimostrate

Python, machine learning, feature engineering, dati geospaziali, interpretabilità, data visualization, collaborazione cross-funzionale.

> Nota: progetto realizzato in contesto professionale. Per riservatezza aziendale non sono pubblicati codice, dati, formule di scoring, pesi, metriche operative, dashboard, clienti o dettagli implementativi.
